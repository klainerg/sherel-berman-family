# שורשי משפחות שרל וברמן

אתר סטטי בעברית וב־RTL, ללא התקנה וללא בסיס נתונים. התוכן בנוסח המשפחה שהועבר בשיחה; פרטי ההפניות ההיסטוריות טרם צורפו. האתר נבנה בפרויקט נפרד.

אתר ההשראה הוא [שורשי משפחת קליינר](https://klainerg.github.io/kleiner-family/), במאגר [klainerg/kleiner-family](https://github.com/klainerg/kleiner-family). מבנה המאגר, מנגנון טעינת TXT, תחביר התמונות, חלון ההגדלה, העיצוב והוראות הפרסום נבדקו ב־13 בנובמבר 2026. נשמרו הרקע, צבעי הירוק והזהב, סגנון הכותרות והטקסט, הניווט לצד הסיפור והפרדת התוכן. באתר החדש נוספו מסלולי המשפחה והערות השוליים. פורמט chapters.json מורחב כדי לאפשר שמות, כותרות וחלקים. לא בוצעו שינויים במאגר קליינר.

## עריכת הסיפור

פתחו ב־GitHub את תיקיית `content`, בחרו קובץ TXT ולחצו על העיפרון לעריכה. שמרו באמצעות Commit changes. פסקאות מופרדות בשורה ריקה. כותרת פנימית מתחילה ב־`## `.

- `intro.txt` — הפתיחה.
- `sherel.txt` — משפחת שרל.
- `berman.txt` — משפחת ברמן ופורמן.
- `together.txt` — המשפחה המאוחדת.
- `epilogue.txt` — אחרית דבר.

הקבצים נשמרים בקידוד UTF-8. אין צורך לשנות HTML כדי לעדכן את הסיפור.

## תמונות ומסמכים

העלו את התמונות לתיקייה `assets/images` באמצעות Add file → Upload files. השאירו את שמות הקבצים בדיוק כפי שהם מופיעים בטקסט, כולל אותיות קטנות וסיומת. לדוגמה, בשורה נפרדת ובין שורות ריקות:

```text
[[תמונה: zakharia-sherel.jpg | זכריה שרל, סבא רבא של נליה]]
```

כל עוד הקובץ חסר, מוצג מקום שמור עם כיתוב. לאחר ההעלאה התמונה תופיע אוטומטית. לחיצה פותחת הגדלה, עם כפתורי + ו־− וגלילה לצפייה במסמכים גם בטלפון. Escape סוגר את ההגדלה. השתמשו בשמות קובץ באנגלית ללא רווחים.

## הוספת פרק

צרו קובץ TXT נוסף ב־`content`. הוסיפו פריט לרשימה שב־`content/chapters.json`, בסדר שבו תרצו שיופיע. אין צורך בשינוי קוד. דוגמה לפריט:

```json
{"id":"next-generation","title":"הדור הבא","file":"next-generation.txt","label":"פרק נוסף"}
```

ה־id חייב להיות ייחודי, באותיות אנגליות קטנות ובמקפים. יש להפריד פריטים בפסיק ולשמור על JSON תקין. הכותרת והניווט מתעדכנים מתוך הרשימה.

## מקורות והערות שוליים

בגוף הטקסט הוסיפו `[[מקור: orinin]]`. ב־`content/sources.json` יש פריט עם אותו `id`, כותרת `title`, פירוט `note` וקישור `url`. הקישורים חייבים להתחיל ב־https:// או http://. עד לצירוף הקישור השאירו מחרוזת ריקה בשדה url ועדכנו את ההערה כשפרטי המקור יושלמו. המספור ורשימת המקורות נוצרים אוטומטית לפי סדר המקורות בקובץ. מקורות המוזכרים שוב מקבלים אותו מספר.

## פרסום ב־GitHub Pages

השם המוצע למאגר החדש: `sherel-berman-family`. העלו אליו את תוכן התיקייה הזו, כך ש־`index.html` יהיה בשורש המאגר, בענף `main`. אין להעלות את האתר לתוך מאגר קליינר.

במאגר החדש בחרו Settings → Pages → Source → GitHub Actions. תהליך הפרסום המוכן נמצא ב־`.github/workflows/pages.yml`; לאחר ההגדרה הפעילו אותו ב־Actions → פרסום האתר → Run workflow, או שמרו שינוי נוסף. לאחר הצלחה כתובת האתר מופיעה ב־Settings → Pages ובתוצאת הפרסום. כל שמירה עתידית בענף main מפעילה פרסום מחדש.

אפשר גם לבחור Deploy from a branch, בענף main ובתיקיית root, במקום תהליך Actions.

## תצוגה מקומית

עם Node.js מותקן, הריצו מתוך תיקיית האתר:

```text
node preview.cjs
```

פתחו http://127.0.0.1:4173 בדפדפן. אין לפתוח את index.html בלחיצה כפולה, כי הדפדפן צריך לטעון את קובצי התוכן דרך שרת. Ctrl+C מפסיק את התצוגה. אין תלות בחבילות חיצוניות.
