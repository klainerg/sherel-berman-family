# שורשי משפחות שרל וברמן

אתר סטטי בעברית וב־RTL, ללא התקנה וללא בסיס נתונים. התוכן בנוסח המשפחה שהועבר בשיחה; פרטי ההפניות ההיסטוריות טרם צורפו. האתר נבנה בפרויקט נפרד.

אתר ההשראה הוא [שורשי משפחת קליינר](https://klainerg.github.io/kleiner-family/), במאגר [klainerg/kleiner-family](https://github.com/klainerg/kleiner-family). מבנה המאגר, מנגנון טעינת TXT, תחביר התמונות, חלון ההגדלה, העיצוב והוראות הפרסום נבדקו ב־13 בנובמבר 2026. נשמרו הרקע, צבעי הירוק והזהב, סגנון הכותרות והטקסט, הניווט לצד הסיפור והפרדת התוכן. באתר החדש נוספו מסלולי המשפחה והערות השוליים. פורמט chapters.json מורחב כדי לאפשר שמות, כותרות וחלקים. לא בוצעו שינויים במאגר קליינר.

## עריכת הסיפור

פתחו ב־GitHub את תיקיית `content`, בחרו קובץ TXT ולחצו על העיפרון לעריכה. שמרו באמצעות Commit changes. פסקאות מופרדות בשורה ריקה. כותרת פנימית מתחילה ב־`## `.

- `intro.txt` — הפתיחה.
- `sherel.txt` — משפחת שרל.
- `berman.txt` — משפחת ברמן ופורמן.
- `together.txt` — המשפחה המאוחדת.
- `epilogue.txt` — אחרית דבר.

הקבצים נשמרים בקידוד UTF-8. אין צורך לשנות HTML כדי לעדכן את הסיפור.

## תמונות ומסמכים

העלו את התמונות לתיקייה `assets/images` באמצעות Add file → Upload files. השאירו את שמות הקבצים בדיוק כפי שהם מופיעים בטקסט, כולל אותיות קטנות וסיומת. לדוגמה, בשורה נפרדת ובין שורות ריקות:

```text
[[תמונה: iosif-sherel-uniform.png | יוסף שרל במדים]]
```

התמונה מופיעה לאחר העלאת הקובץ. סימון של קובץ חסר אינו מציג שומר מקום באתר. לחיצה פותחת הגדלה, עם כפתורי + ו־− וגלילה לצפייה במסמכים גם בטלפון. Escape סוגר את ההגדלה. השתמשו בשמות קובץ באנגלית ללא רווחים.

תמונות לדוגמה המשולבות בסיפור:

- iosif-sherel-uniform.png — יוסף במדים, רביעי משמאל.
- grisha-sherel-uniform.jpeg — גרישה במדים.
- sherel-family-group.png — התמונה המשפחתית.
- dasha-at-work.png — דשה בעבודה.
- nelia-child.png — נליה בילדותה.
- igor-and-gena.png — איגור וגנה הקטן.

## הוספת פרק

צרו קובץ TXT נוסף ב־`content`. הוסיפו פריט לרשימה שב־`content/chapters.json`, בסדר שבו תרצו שיופיע. אין צורך בשינוי קוד. דוגמה לפריט:

```json
{"id":"next-generation","title":"הדור הבא","file":"next-generation.txt","label":"פרק נוסף"}
```

ה־id חייב להיות ייחודי, באותיות אנגליות קטנות ובמקפים. יש להפריד פריטים בפסיק ולשמור על JSON תקין. הכותרת והניווט מתעדכנים מתוך הרשימה.

## מקורות והערות שוליים

בגוף הטקסט הוסיפו `[[מקור: orinin]]`. ב־`content/sources.json` יש פריט עם אותו `id`, כותרת `title`, פירוט `note` וקישור `url`. הקישורים חייבים להתחיל ב־https:// או http://. עד לצירוף הקישור השאירו מחרוזת ריקה בשדה url ועדכנו את ההערה כשפרטי המקור יושלמו. המספור ורשימת המקורות נוצרים אוטומטית לפי סדר המקורות בקובץ. מקורות המוזכרים שוב מקבלים אותו מספר.

## פרסום ב־GitHub Pages

האתר פורסם במאגר [klainerg/sherel-berman-family](https://github.com/klainerg/sherel-berman-family). כתובת האתר: https://klainerg.github.io/sherel-berman-family/

הפרסום מוגדר ב־Settings → Pages → Deploy from a branch, בענף main ובתיקיית root. לאחר כל עריכה ושמירה בענף main האתר מתפרסם מחדש אוטומטית. אפשר לעקוב אחר התהליך בלשונית Actions. אין צורך בבנייה או בהתקנת חבילות. אין להעלות את הקבצים למאגר קליינר.

## העץ המשפחתי והטאבים

סיפורי שרל וברמן מופיעים באותו אזור, בשתי לשוניות. כל לשונית זוכרת את מקום הקריאה שלה. אפשר להגיע לכל אחד מהענפים גם דרך תוכן העניינים או קישור ישיר. הכפתור הקבוע ״חזרה למקום הקודם״ מחזיר גם את הלשונית וגם את מיקום הגלילה לאחר קפיצה למקור, לאדם בעץ או לפרק אחר.

העץ המשולב נמצא במדור ״עץ המשפחה״. גרירה בעכבר או באצבע מזיזה אותו, צביטה בשתי אצבעות וכפתורי +/− משנים את ההגדלה. במחשב אפשר גם Ctrl וגלגלת. כפתורי המיקוד מציגים את שרל, ברמן ופורמן, גרישה ודשה, או את כל העץ. מקשי החצים מזיזים את העץ; רשימת השמות מציעה חלופה ללא גרירה. לחיצה על שם פותחת פרטים וקישור לסיפור.

הנתונים נמצאים בקובץ `family-tree.json` שבשורש המאגר: `people` מכיל שמות, פרטים, הפניות לפרקים ומיקום בתרשים; `couples` מכיל זוגות וילדיהם; `parents` מכיל קשרי הורה וילדים; `ancestry` מסמן בקו מקווקו קשר לדורות קודמים. אין להחליף קשר כללי בקשר הורה־ילד בלי מידע משפחתי מתאים. השמות ״פימה שרל״ ו״פימה קליינר״, ו״גרישה שרל״ ו״גרישה ברמן״ נשמרים כאנשים נפרדים.

## הפעלה מקומית

עם Node.js מותקן, הריצו מתוך תיקיית האתר:

```text
node preview.cjs
```

פתחו http://127.0.0.1:4173 בדפדפן. אין לפתוח את index.html בלחיצה כפולה, כי הדפדפן צריך לטעון את קובצי התוכן דרך שרת. Ctrl+C מפסיק את התצוגה. אין תלות בחבילות חיצוניות.


## ציר הזמן בקריאה

ציר זמן צף מופיע בשוליים רק בעת קריאת הסיפור. הוא עוקב אחר הענף הפעיל והקטע שמוצג, ומאפשר קפיצה לאירוע. במחשב מוצגים גם שמות האירועים; בטלפון מוצג פס צר בתוך השוליים, עם סימונים ושנה. ההגדרות נמצאות בקובץ reading-timeline.js. ליד כותרת העץ נוסף כפתור חזרה להתחלה.


## עברית ורוסית

בחירת השפה מופיעה בראש האתר. אפשר לפתוח ישירות את הגרסה הרוסית בכתובת https://klainerg.github.io/sherel-berman-family/?lang=ru ואת הגרסה העברית עם ?lang=he. הבחירה נשמרת בדפדפן; מעבר שפה שומר את הפרק או האירוע הנוכחי. העברית מוצגת מימין לשמאל והרוסית משמאל לימין.

התוכן העברי נשאר בקובצי TXT המקוריים. לכל קובץ יש תרגום מקביל עם הסיומת -ru, למשל content/sherel.txt מול content/sherel-ru.txt. לכל גרסה אותו סדר פסקאות, כותרות, תמונות והפניות למקורות. בעריכת הסיפור יש לעדכן את שתי הגרסאות. רשימות הפרקים והמקורות הרוסיות הן chapters-ru.json ו־sources-ru.json.

תרגום השמות והפרטים של כל 30 הרשומות בעץ נמצא ב־family-tree-ru.json. הקשרים, המיקומים והמזהים משותפים ונלקחים מ־family-tree.json. תרגומי הפקדים והניווט נמצאים ב־language-data.js. אין לשנות את מזהי הפרקים או האנשים בין השפות.

## אנגלית ותיקון משפחת דיק

נוספה בחירת English וכתובת ישירה ?lang=en. התרגומים האנגליים נמצאים בקובצי content/*-en.txt, ברשימות chapters-en.json ו־sources-en.json, ובעץ family-tree-en.json. תרגום הניווט נמצא ב־language-data-en.js. יש לעדכן את שלוש השפות במקביל. לרוזה וסניה דיק שלושה ילדים: בלה, ישה וברוניה; אותו מזהה bronya משמש בכל גרסאות העץ.
